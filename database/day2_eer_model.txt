MySQL Workbench EER Model for TXNORYX Day 2
============================================

Tables:
--------
1. users
   - id: BIGINT, PRIMARY KEY, AUTO_INCREMENT
   - name: VARCHAR(255), NOT NULL
   - email: VARCHAR(255), NOT NULL, UNIQUE
   - phone: VARCHAR(255)
   - role: VARCHAR(50)
   - created_at: DATETIME

2. transactions
   - id: BIGINT, PRIMARY KEY, AUTO_INCREMENT
   - transaction_id: VARCHAR(255), NOT NULL, UNIQUE
   - user_id: BIGINT, FK -> users(id)
   - amount: DECIMAL(15,2), NOT NULL
   - currency: VARCHAR(3), NOT NULL
   - payment_method: VARCHAR(50)
   - merchant: VARCHAR(255)
   - status: VARCHAR(50)
   - failure_reason: VARCHAR(255)
   - device_id: VARCHAR(255)
   - location: VARCHAR(255)
   - created_at: DATETIME

3. transaction_events
   - id: BIGINT, PRIMARY KEY, AUTO_INCREMENT
   - transaction_id: VARCHAR(255), NOT NULL
   - event_type: VARCHAR(100), NOT NULL
   - description: VARCHAR(255), NOT NULL
   - timestamp: DATETIME, NOT NULL

Relationships:
--------------
- transactions.user_id -> users.id (FOREIGN KEY)
- transaction_events.transaction_id -> transactions.transaction_id (implicit via event tracking)

Index Recommendations:
---------------------
- users.email: UNIQUE INDEX
- transactions.transaction_id: UNIQUE INDEX
- transactions.user_id: INDEX
- transaction_events.transaction_id: INDEX

Sample Data Inserts:
--------------------
-- Insert a user:
INSERT INTO users (name, email, phone, role, created_at)
VALUES ('Test User', 'test@txnoryx.com', '1234567890', 'USER', NOW());

-- Insert a transaction:
INSERT INTO transactions (transaction_id, user_id, amount, currency, payment_method, merchant, status, created_at)
VALUES ('TXN-001', 1, 1850.00, 'INR', 'UPI', 'Test Merchant', 'PENDING', NOW());

-- Insert a transaction event:
INSERT INTO transaction_events (transaction_id, event_type, description, timestamp)
VALUES ('TXN-001', 'TRANSACTION_CREATED', 'Transaction created successfully', NOW());
